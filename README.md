# Robo-Omnidirecional-PID
Projeto de Iniciação Científica desenvolvido na UFABC para implementação e validação de um sistema de controle baseado em PID aplicado a um robô móvel omnidirecional com rodas mecanum. O sistema utiliza um Raspberry Pi Pico (RP2040) e uma IMU MPU-9250 para estimativa de orientação e controle em malha fechada.
